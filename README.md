# marketing-context-starter

A starter template for keeping your AI project context in files you own, so you
can pick up where you left off across AI tools and computers.

## What's inside

```
.gitignore                  Keeps common credential and temporary files out of Git
Marketing - Newsletter/     An example project folder
  CLAUDE.md                 Who you are, who you write for, how you write, what AI must never do
  handoff.md                What's done, where you left off, what happens next
  decisions.md              Decisions you've confirmed, kept separate from suggestions
  outputs/                  Drafts and other text worth keeping
```

The handoff, decisions, and outline files show a real first session, so you can
see what they look like after AI has worked in the folder.

## How to use it

1. Click **Code**, then **Download ZIP**, and unzip it.
2. Copy `.gitignore` into your own private `marketing-context` repository.
3. Copy the `Marketing - Newsletter` folder in and rename it for your project.
4. Replace the example role, audience, and rules in `CLAUDE.md` with your own.
5. Clear out `handoff.md`, `decisions.md`, and `outputs/` and start fresh.

Keep your own repository **private**. Never store passwords, API keys, or
confidential client information in it. A `.gitignore` file helps, but it won't
catch everything, so review every change before you commit.
